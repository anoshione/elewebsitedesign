# e-Learning & Earning Ltd. — Official Website & Learning Platform

A modern, high-performance landing page and course discovery platform built with **React 19**, **Vite**, **Tailwind CSS v4**, and custom **Glassmorphism** styling.

---

## 🌟 Key Features

- **Full Course Catalog**: Categorized by department with filtering, interactive syllabus drawers, pricing, and discount modals.
- **Glassmorphic UI**: Signature `.glass` blur effects, translucent navigation bar with hide-on-scroll behavior, circular badges, and clean typography.
- **Interactive Success Stories**: 16:9 documentary video cards with realistic cinematic stills and interactive video modals.
- **Course & Department Explorer**: Department tabs with custom iconography, outcome statistics, and curriculum highlights.
- **Student Reviews Carousel**: Authentic student reviews with track badges, verified outcomes, and ratings.
- **FAQ & Counseling Hub**: Expandable accordion questions and direct consultation booking.
- **Responsive & Accessible**: Optimized for all screen sizes from mobile to ultra-wide desktop monitors.

---

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism CSS
- **Icons**: Lucide React
- **Deployment Target**: Vercel (Single Page Application with Vite preset)

---

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/anoshione/elewebsitedesign.git
   cd elewebsitedesign
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local dev server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the site.

4. **Production Build**:
   ```bash
   npm run build
   ```

---

## ☁️ Deploy to Vercel

### Option 1: Vercel Dashboard (Recommended)

1. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New"** > **"Project"**.
2. Select your repository: `anoshione/elewebsitedesign`.
3. Vercel automatically detects Vite:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
4. Click **Deploy**. Your site will be live with automatic SSL and continuous deployment!

### Option 2: Vercel CLI

```bash
npm i -g vercel
vercel
```
